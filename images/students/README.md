# Student headshots

- Add headshot images here as `images/students/<slug>.jpg` (e.g. `sanjay-chandrasekaran.jpg`). The `<slug>` for each student is in `_data/students.yml`.
- If a headshot is missing, the Students page shows a gray placeholder (no file needed).
- Optional: add `placeholder.jpg` for a site-wide default fallback; otherwise the in-page fallback is used.
